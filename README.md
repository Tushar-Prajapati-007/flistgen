# flistgen
Reads *.v and *.sv files to create two filelist rtl_filelist.f and tb_filelist.f 

# why?
  Too lazy to create filelist for my project flow based on euclide

## usage 
1. download the flistgen file
2. change permision
```bash
chmod +x ./flistgen
```
3. invoke ./flistgen in you desired location
4. select files for rtl and tb at once
